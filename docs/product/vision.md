# Product Vision

## Purpose

Spectre is a desktop offline-first application for personal wealth management and smart portfolio rebalancing.

## Core Problem

> "I have R$ X to invest this month. Which assets should I invest in, and how much in each, to bring my portfolio closer to my target allocation?"

## Core Principle

Rebalancing happens exclusively through **new contributions**. The system never suggests selling assets, manual reallocation, aggressive rebalancing, trading, or market timing.

## Target Users

- Individual investors with multiple accounts and portfolios
- Users who want to correct allocation deviations using only new money
- Portuguese-speaking users (Brazil)

## Key Differentiator

Smart Contribution Rebalancer: instead of passive tracking, the system actively suggests where to allocate new money to optimize portfolio alignment with the target.
