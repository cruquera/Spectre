# Portfolio Strategies

## Concept

Every portfolio template has a strategy. The strategy defines how the user structures their asset allocation.

## Strategies

### FREE_ALLOCATION (Recommended)

Flat allocation. User defines direct percentages for each asset. Sum must be 100%.

### ASSET_CLASS_ALLOCATION

Hierarchical. User defines class-level percentages (sum 100%), then within each class defines sub-targets (sum 100% per class). Flattened for rebalancing via Allocation Tree.

## Default

FREE_ALLOCATION is the default for backward compatibility.
